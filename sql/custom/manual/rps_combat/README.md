# Ручные операции RPS Combat

Каталог `sql/custom/manual/rps_combat` находится вне автоматических `updates_include` отдельных баз. Обычная установка и миграции описаны в [SQL RPS и NobleNext](../../README.md). Перед каждым ручным запуском выберите нужную базу, сохраните резервную копию и остановите worldserver и другие процессы записи. Выполняйте файлы SQL-клиентом, который останавливается при ошибке.

| База | Файл | Действие |
|---|---|---|
| CHARACTERS | [2026_10_27_00_rps_min_level_10.sql](characters/2026_10_27_00_rps_min_level_10.sql) | Поднимает всех персонажей ниже 10-го уровня до 10 и обнуляет их опыт. Нужен явный выбор владельца. |
| CHARACTERS | [2026_10_27_10_rps_starter_outfit_mail.sql](characters/2026_10_27_10_rps_starter_outfit_mail.sql) | Первая разовая рассылка стартового комплекта существующим персонажам. |
| CHARACTERS | [2026_10_27_11_rps_starter_outfit_mail_v2.sql](characters/2026_10_27_11_rps_starter_outfit_mail_v2.sql) | Разовая рассылка второго комплекта. Сохраняет отдельную метку и квитанции. |
| WORLD | [2026_10_27_02_rps_xp_for_level.sql](world/2026_10_27_02_rps_xp_for_level.sql) | Заменяет значения таблицы опыта для уровней 10–18. |
| WORLD | [2026_10_27_07_rps_playercreateinfo_cloth.sql](world/2026_10_27_07_rps_playercreateinfo_cloth.sql) | Сохраняет прежний состав и заменяет всю `playercreateinfo_item` на комплект RPS. Согласуйте `RPS.StarterOutfit.ReplaceLoadout = 1`. |

При установке с нуля сначала выполните автоматические пакеты HOTFIXES, WORLD и CHARACTERS. Затем выберите ручные WORLD-настройки для своего мира. Рассылки предназначены для уже существующих персонажей. Их метки защищают повторную выдачу. Для работы редактора персонажа и профилей RPS массовое повышение уровня не требуется.

На существующей базе перед повторным запуском сверяйте `rps_migration_marks`, `rps_action_receipts` и `rps_custom_data_packages`, а также фактические предметы, письма и состав старта. После ошибки заново подключитесь к базе. Временные таблицы принадлежат текущему соединению. Файлы сохраняют собственные транзакции и проверки, полный набор ручных операций выполняется по выбранному плану.
